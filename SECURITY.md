# Security policy

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue.

1. Go to the repository's **Security** tab and choose **Report a vulnerability**
   (GitHub private vulnerability reporting):
   https://github.com/mmelqadi/twinlane/security/advisories/new
2. Describe the problem, the affected version, and the steps to reproduce it.

You will get an acknowledgement within 7 days. Once a fix is ready it is
released and the advisory is published with credit to the reporter, unless
you ask to stay anonymous.

## Supported versions

Only the latest release receives security fixes.
