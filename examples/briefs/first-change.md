# First writing task

Read README.md and identify one small wording or formatting improvement that would help a new user.

Make the smallest useful edit to one Markdown documentation file inside this linked worktree. Preserve all technical claims, limitations, commands, and exact text required by existing documentation tests.

Do not change runtime code, dependencies, CI, or tests. Do not commit, push, merge, or contact external services.

In the final result, explain what changed and why, and identify the file to review. If no useful small change is justified, explain that instead of making an unnecessary edit.
